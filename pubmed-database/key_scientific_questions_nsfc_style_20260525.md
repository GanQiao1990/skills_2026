# 拟解决的关键科学问题（国自然/重点项目风格成稿）

本项目面向原核微生物高效生产氨基酸过程中普遍存在的动态失配与局部反应效率不足两类核心瓶颈，拟以 de novo 设计的可编程临近元件为技术基础，建立从元件设计、胞内筛选到生产部署的蛋白层级调控框架。与现有以转录调控、基因剂量调节和发酵工艺优化为主的系统代谢工程路线不同，本项目关注的是：在既有高价值调控节点已经较明确的前提下，能否引入可逆、可阶段化、可局部化的蛋白执行模块，实现对生产状态和反应空间组织的精细干预。围绕这一目标，项目拟重点解决以下两个关键科学问题。

## 1. 如何利用 de novo 设计的可编程临近元件，对氨基酸高产过程中的动态状态失配实施蛋白层级实时门控？

高产氨基酸发酵并非单一限速酶不足所致，而是生产过程中氮源利用、redox/ATP 分配、产物输出与生长-生产阶段切换之间存在持续变化且相互耦合的动态失配。现有研究表明，这类失配通常发生于生产后期，是限制高产菌株进一步提升滴度、强度和阶段产率的关键原因。然而，传统代谢工程主要依赖启动子替换、基因过表达、竞争支路敲除及发酵参数调节等手段，虽能在转录层和过程层改善产量，但对生产阶段快速切换、瞬时状态重构以及蛋白互作层面的精细控制仍然不足。

本项目拟回答的第一个关键科学问题是：能否利用 de novo 设计的可编程临近元件，将 NarL 等状态响应节点及其下游直接执行节点组织为生产阶段可切换的蛋白级控制模块，从而在不改变底层代谢网络基本架构的前提下，实现对氮状态、redox/ATP 状态与生长-生产转换窗口的实时门控，并获得传统静态调控难以实现的额外生产收益。该问题的实质，在于验证 de novo 蛋白元件能否从“结合识别部件”提升为“动态状态执行器”，并建立其在原核氨基酸高产体系中的适用边界、作用层级与评价准则。

## 2. 如何利用 de novo 设计的空间组织元件，提高关键反应节点的局部反应效率并减少扩散损失？

氨基酸生物合成及其相关调控过程普遍涉及连续多步酶促反应、局部辅因子耦联和多个竞争支路并存。传统过表达策略虽然能够提高单个酶的丰度，但难以解决中间体在胞内自由扩散过程中被竞争支路截流、被稀释消耗或因局部供能/供还原力不足而降低有效转化效率的问题。因此，在部分高产场景中，限制生产性能的关键已不再仅仅是“酶量不足”，而是“关键节点未被组织为高效局部反应单元”。

本项目拟回答的第二个关键科学问题是：能否利用 de novo 设计的可编程空间组织元件，将关键连续反应酶、调控蛋白及输入/输出节点重构为局部高效反应单元，从而缩短有效传递距离，提高主通路优先级，减少中间体扩散损失与竞争支路截流，并最终提升目标氨基酸合成的局部反应效率与整体生产性能。该问题的核心，不在于简单构建一个静态 scaffold，而在于建立一种可设计、可筛选、可部署的蛋白空间组织策略，使传统代谢工程中的“通量优化”进一步推进为“局部反应组织优化”。

## 压缩版表述（适合直接放入申请书小节开头）

本项目拟解决两个关键科学问题：其一，阐明 de novo 设计的可编程临近元件能否作为蛋白层级动态执行模块，对氨基酸高产过程中氮状态、redox/ATP 状态及生长-生产切换失配实施实时门控；其二，阐明 de novo 设计的空间组织元件能否将关键反应与调控节点重构为局部高效反应单元，以减少扩散损失和竞争支路截流，并提高目标通路的局部反应效率与整体生产性能。

## 一句话版本（适合摘要或图示总述）

本项目旨在回答：de novo 设计的可编程蛋白元件，能否同时承担高产氨基酸体系中的“动态状态控制器”和“局部空间组织器”两类核心功能。

# Paid Media Strategy Umbrella

Use this as the class-level entry point for paid media work. It replaces narrow channel/session skills with a single workflow and reference bank.

## Core workflow
1. Clarify business objective: revenue, qualified pipeline, signups, retention, or awareness.
2. Establish measurement: conversion events, attribution window, CAPI/GTM/GA4/server-side tracking, UTMs, offline conversions.
3. Audit account structure: campaigns, audiences, match types, exclusions, creative, budgets, bid strategies, learning status.
4. Diagnose performance: spend mix, marginal CPA/ROAS, funnel drop-off, query waste, creative fatigue, impression share, frequency, quality score.
5. Recommend action by lever: budget allocation, bidding, structure, negatives, audiences, feed, creative, landing page, tracking.
6. Define tests with guardrails: hypothesis, audience, budget, duration, success metric, stop-loss, readout format.

## Subdomains
- **PPC/search**: Google Ads, Microsoft Ads, Amazon Ads; keyword architecture, match types, negatives, Quality Score, PMax/Shopping.
- **Paid social**: Meta, LinkedIn, TikTok; audience strategy, creative iteration, frequency/fatigue, CAPI.
- **Programmatic/display**: DV360, Trade Desk, GDN; inventory quality, brand safety, viewability, reach/frequency.
- **Creative strategy**: RSA variants, hooks, offers, visual angles, testing matrices.
- **Search query analysis**: mine waste, intent, negatives, expansion opportunities.
- **Tracking**: conversion event hierarchy, deduplication, pixel/server events, UTM governance.
- **Audit**: summarize account health, risks, quick wins, and structural rebuilds.

# Testing Quality Engineering

Use this class-level skill for testing and quality work.

## Core workflow
1. Define risk: user impact, system boundary, release gate, compliance/safety needs.
2. Build a test matrix: happy path, edge cases, negative tests, regression, performance, accessibility, integration.
3. Execute with evidence: commands, screenshots, logs, metrics, environment, commit/version.
4. Classify findings by severity, reproducibility, scope, and release impact.
5. Recommend go/no-go, mitigations, follow-up tests, and monitoring.

## Subdomains
- **API testing**: contracts, auth/authz, schema, rate limits, security basics, load.
- **Accessibility**: WCAG, keyboard, screen reader, contrast, semantics.
- **Embedded QA**: HIL, firmware, OTA, EMC/ESD planning.
- **Evidence collection**: proof chain for claims and sign-off.
- **Performance benchmarking**: load, latency, capacity, profiling.
- **Reality checker**: skeptical production-readiness review.
- **Results analyzer**: summarize failures, flake, trends, quality metrics.
- **Tool evaluator**: compare testing tools by cost, fit, reliability.
- **Workflow optimizer**: improve QA process throughput and reliability.

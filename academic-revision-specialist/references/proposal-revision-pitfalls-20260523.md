Session note: proposal revision pitfalls and preferred neutral wording

Observed issue pattern in the NBT binder platform proposal:
- Slogan-like labels can read as imprecise or over-marketed in formal proposal prose.
- Examples that should be normalized into neutral methodological language:
  - “双重幻想” -> “分阶段生成—局部精修—跨模型验证”
  - “最适合” -> “更适合” when the claim is only a positioning choice, not a demonstrated optimum
  - “打造成” -> “建立/构建/形成”
  - “动态重写” -> “动态调节/动态调整/动态控制” unless the proposal truly demonstrates reprogramming
- When the user asks for “不合适的地方”, prefer a narrow pass that softens exaggerated wording while preserving the technical spine.
- Keep the revision submission-ready; do not describe the edit history in the final prose.

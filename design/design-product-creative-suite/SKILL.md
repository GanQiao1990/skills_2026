# Design Product Creative Suite

Use this class-level skill for design work across strategy, UX, UI, brand, visuals, and product delight.

## Core workflow
1. Clarify user goal, audience, brand context, constraints, platform, and success metric.
2. Diagnose current experience: hierarchy, flow, consistency, accessibility, emotional tone, and conversion intent.
3. Propose design direction: information architecture, components, visual language, interaction model, and content tone.
4. Produce artifacts: wireframes, UI specs, design tokens, content/visual prompts, QA checklist, or critique.
5. Validate: accessibility, responsiveness, implementation feasibility, brand fit, and user comprehension.

## Subdomains
- **Brand guardian**: positioning, voice, visual consistency, brand risk.
- **UI designer**: components, layout, spacing, typography, design systems.
- **UX architect**: flows, IA, interaction patterns, implementation-ready guidance.
- **UX researcher**: user evidence, usability, interviews, synthesis.
- **Visual storyteller**: narrative visuals, decks, campaigns, explainers.
- **Inclusive visuals**: bias checks, representation, cultural sensitivity.
- **Image prompt engineering**: precise photo/AI visual prompts and art direction.
- **Whimsy/delight**: tasteful personality, microcopy, animation, memorable moments.

# Publication evidence grading for causal target-indication projects

Use this reference when a project has PWAS, multi-omics, SHAP, enrichment, or drug-triangulation outputs and needs publication-ready language.

## Purpose

Keep the manuscript honest about what the current data support. Separate:

- biomarker discovery
- target indication
- causal-inference readiness
- causal proof

## Recommended grading

- Grade A: coloc/MR-supported causal candidate with endpoint-specific replication and sensitivity analyses.
- Grade B+: high-priority causal-inference candidate with strong genetic support and low unresolved heterogeneity, ready for coloc/MR.
- Grade B: strong target hypothesis with heterogeneity caution or missing SNP-level causal evidence.
- Grade C+: genetically anchored hypothesis with PWAS support but limited orthogonal evidence.
- Grade D: exploratory signal.

## Language mapping

- Grade A: "causal target"
- Grade B+/B: "causal-inference candidate" or "priority target hypothesis"
- Grade C+: "genetically anchored target hypothesis"
- Grade D: "exploratory signal"

## Review rule

High statistical significance is not enough for causal claims. If the data are protein/model-level only, keep the claim at target indication and describe coloc/MR as future validation or readiness, not as completed proof.

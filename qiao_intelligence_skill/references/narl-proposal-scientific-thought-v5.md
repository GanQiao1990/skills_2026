# NarL 项目 proposal 科学思想写法（v5）

适用场景：当任务是基于 `/home/qiao/qiao_design/narl_project` 的现有材料，撰写或重写中文 proposal / grant-style 研究方案，并且用户要求“with 科学思想”或强调方法学主线时。

## 总体主线
不要把内容写成几个平行小课题堆砌；要统一成一条平台化主线：

设计 → 筛选 → 调控 → 感知

在 NarL 项目中，推荐展开为：
1. binder 设计为什么不够
2. 为什么要设计双重幻想方法
3. 如何用 ClpX 完成功能筛选
4. 如何把 binder 部署到 S/T/Y 磷酸化抗胁迫调控
5. 如何把 binder 部署到 NarQ–NarL 动态生产调控
6. 如何用 ppGpp binder + cpGFP 做胁迫感知

## 必写的方法学判断
### 1. 现有方法的总判断
要明确写成一句：

- 现有方法的问题：要么慢，要么易错。

展开时建议对应为：
- RFdiffusion / BindCraft 等扩散类路线：多轮迭代，计算速度慢，资源消耗大。
- ProteinHunter / HalluDesign 等单幻想路线：速度快，但强依赖单一模型或单一模型家族，易出现自证偏差与模型假阳性。

### 2. 双重幻想方法的定义
不要写成“多跑一轮模型”。要写成职责分离：

- 第一重幻想：广域探索
- 第二重幻想：局部精修

推荐解释：
- 第一重幻想负责快速提出粗粒度拓扑和 candidate family，最大化扩大搜索空间并保持效率。
- 第二重幻想负责在候选序列化后引入更严格的物理约束、界面微环境调整和结构—序列闭环精修，保证候选不仅生成得快，而且能在更严格条件下站得住。

### 3. 正交验证的写法
必须强调：
- 不追求单一模型闭环高分
- 追求跨模型最小共识

推荐点名：
- Boltz-2
- AF3
- Chai-1

推荐表述：
- 两轮幻想后引入多项独立预测/审计模块实施跨模型正交复核，主动压缩候选并剔除模型特异性错误。

## ClpX 筛选部分的固定写法
当 proposal 涉及 binder 筛选时，优先采用以下逻辑：

### 1. 立题角度
从效率与经济角度写，而不是只写“验证 binding”。

### 2. 系统构型
明确写：
- ClpX binder–linker–GFP binder
或
- ClpX binder–linker–target binder

### 3. 理论基础
固定写法：
- 基本理论基础为临近效应。

### 4. 功能评价标准
固定写法：
- 靶点降解越多越好。

即：优先把 binding 转成细胞内可放大的功能 readout，再根据降解强弱排序候选。

### 5. 正交验证
固定写法：
- SPR 用于高优先级命中的正交验证。

推荐顺序：
ClpX/ClpXP 功能初筛 → 命中优先级排序 → SPR 动力学复核

## 其余三条主线的推荐写法
### S/T/Y 磷酸化抗胁迫
- 先用 S/T/Y 磷酸化测序识别精氨酸胁迫下关键变化
- 再用 binder-linker 或小分子调控 binder-靶点蛋白 binder 模块，定向重写关键位点磷酸化
- 写成“提高细胞抗胁迫能力”的方案，不要写成既成结果

### NarQ–NarL 动态生产调控
- 先解析 NarL 与生长—生产切换之间的关系
- 再写通过 NarQ 动态调控 NarL 达到促进生产
- 重点不是“单纯增强 NarL”，而是动态调节 NarL 的磷酸化程度、暴露窗口和作用时相

### ppGpp 感知
- 构建 ppGpp binder + cpGFP 作为胁迫变化实时传感器
- 不只写“做一个传感器”，而要写成整个平台的感知层输入端口

# 氨基酸生物合成瓶颈与条件优化：本地专利语料提炼

适用场景：当用户在 `/home/qiao/qiao_design/e_coli_model/5000万专利申请全量数据1985-2025` 体系内要求调研“氨基酸生物合成过程中的制约因素/瓶颈/条件优化”，且希望结果可直接用于后续项目规划、NarL 映射或 LLM 交互。

## 默认判读
- 若用户写成“制约性引物/条件优化”而上下文明显是发酵、代谢工程、氨基酸高产，则默认优先解释为“制约性因素/瓶颈与条件优化”；不要先把任务带偏到 PCR/qPCR 引物设计，除非用户明确提到扩增、检测、克隆或引物序列。

## 默认方法
1. 优先用本地专利检索栈，不先做泛化网络综述。
2. 先把结论写成“工程高产约束”，不要伪装成完整生化机制综述。
3. 输出时明确：专利证据更偏工业工程与工艺窗口，不应过度外推为普适机理定论。

## 建议的六类瓶颈框架
默认把专利中的高频限制因素收敛为以下六类：
1. 产物毒性、渗透压/酸胁迫、终点掉活
2. 前体供给不足与碳流分配不合理
3. 辅因子/还原力供给不足（NADH/NADPH/PLP/ATP）
4. 关键酶活性、稳定性、反馈抑制与转运不足
5. 静态表达不适配生长-生产切换，需动态调控
6. 发酵工艺窗口未调顺（培养基、补料、DO、pH、阶段切换）

## 常用结论模板
- 不要写成“主要是单一限速酶问题”。
- 优先写成：高产是“底盘耐受性 + 通量重分配 + 辅因子平衡 + 动态调控 + 工艺窗口协同优化”的系统工程。

## 按氨基酸家族归并时的默认重点
- 天冬氨酸家族：草酰乙酸供给、分支竞争、反馈抑制
- 芳香族家族：PEP/E4P、PPP/NADPH、中间体毒性
- 谷氨酸家族：α-KG/谷氨酸节点、外排、PLP 依赖反应
- 支链氨基酸家族：丙酮酸池、分支竞争、redox 与补料窗口

## 推荐交付结构
1. 范围说明（基于本地专利语料）
2. 总体判断
3. 六类高频瓶颈
4. 按氨基酸家族归纳
5. 一个可复用的条件优化流程框架：
   - 先判定主瓶颈
   - 再定代谢硬节点
   - 再拆成通路层/调控层/工艺层
   - 先解决掉活，再追高滴度
   - 辅因子问题单列
   - 最后再用动态调控封顶

## 若后续要映射到 NarL
优先把上述六类瓶颈再拆成：
- 哪些属于氮源切换/硝酸盐利用窗口问题
- 哪些属于 redox / NAD(P)H 再生问题
- 哪些属于 growth-to-production switch 问题
- 哪些主要仍应由底盘耐受和工艺窗口解决

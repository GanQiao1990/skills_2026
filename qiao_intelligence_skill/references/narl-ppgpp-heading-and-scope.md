# NarL–(p)ppGpp 标题与范围约束

适用场景：`/home/qiao/qiao_design/mengjie_huan` 中围绕 NarL、氨基酸/精氨酸胁迫、（p）ppGpp 严谨反应、代谢变化、分子感应器设计与应用的中文学术写作任务。

## 这次会话沉淀出的稳定规则

1. 若用户明确说“write a 四级标题”，默认只交付一个可直接使用的 `####` 标题成品；可在文件中附总标题，但不要擅自扩展成三级标题、简介、提纲或整段说明。
2. 机制词必须前置并保持居中，不要把问题降格为泛泛的“应用研究”或“优化研究”。这一类标题通常需要显式包含以下主线中的大部分：
   - NarL 介导/响应
   - 氨基酸或精氨酸胁迫
   - （p）ppGpp / 严谨反应
   - 代谢重编程或代谢变化
   - 动态变化机制
   - 干预策略
   - AI 设计的感应器 / 应用
3. 对“竞争胜场过程”的表达，应优先学术化处理为“竞争适应优势”“生存竞争优势”或“适应性优势形成”，避免口语化。
4. 当用户后来补充范围词时，应回写并收敛为一个更强的单行标题，而不是继续叠加多个候选版本，除非用户明确要求“备选”。

## 推荐标题骨架

可复用骨架：

`#### NarL介导的[氨基酸/精氨酸]胁迫下（p）ppGpp[严谨反应/动态变化]与[代谢重编程/竞争适应优势]的[机制解析/干预策略及AI感应器设计应用]`

# 刘立明 / Sang Yup Lee 文献调研后对 NarL / de novo 元件 proposal 的两问收口模板

适用场景：
- 用户要求把氨基酸高产、NarL、ppGpp、stress、binder-linker 等平台叙事收束成“两个核心问题”；
- 明确要求“更加要利用我们的设定的 de novo design 元件去执行”；
- 希望用刘立明与 Sang Yup Lee 的代表性研究内容/策略来做文献定位，而不是泛泛综述。

## 一、推荐的两大核心问题

### 问题一：动态状态控制
能否利用 de novo 设计的可编程临近元件，对氨基酸高产过程中“氮状态—redox/ATP—生长/生产切换”的动态失配进行蛋白层级实时门控？

执行层映射：
- NarL / NarQ proximity 元件
- stress-response 调控元件
- ppGpp sensor 作为状态读出/反馈层
- 必要时延伸到 GlnA / GltBD / GdhA / PntAB / 外排蛋白等直接执行节点

### 问题二：空间组织控制
能否利用 de novo 设计的空间组织元件，把关键反应和调控节点重构为局部高效反应单元，从而减少中间体扩散损失和竞争支路截流？

执行层映射：
- binder-linker 酶复合体
- 小分子响应 binder 形成条件性复合体
- 抑制型 / 增强型 binder 对竞争支路或主通路做空间级干预
- ClpX triage 作为胞内功能筛选层

## 二、文献定位时的标准收口

### 刘立明路线
优先归纳为“工业执行型”策略：
- 碳氮协调
- NADPH / ATP 再平衡
- 转运 / 外排 / 耐受
- 生产后期时空解耦
- fed-batch / 5 L 级验证与工艺协同

写法重点：
- 强调高产瓶颈经常发生在生产后期；
- 真正卡点是阶段失配，而不是单酶完全缺失；
- 引出我们需要更快、更可逆、更适合阶段控制的蛋白级执行模块。

### Sang Yup Lee 路线
优先归纳为“系统设计型”策略：
- systems metabolic engineering
- 多模块协同优化
- 底盘—通路—竞争支路—转运—过程条件一体化
- 把高产宿主视为可编程系统而非单点改造对象

写法重点：
- 强调现有路线擅长“找节点”；
- 但对“如何在蛋白层快速、可逆、局部化执行这些节点”仍可进一步推进；
- 引出 de novo 元件平台补的是执行层空位，而不是重复已有系统代谢工程。

## 三、写作时禁止滑回的泛化表述

不要把问题写成：
- 如何进一步系统优化氨基酸高产；
- 如何全面提升底盘性能；
- 如何构建通用高产平台。

优先写成：
- de novo 元件能否做动态状态控制器；
- de novo 元件能否做局部空间组织器；
- 在已知高价值节点上，de novo 元件能否提供传统转录层/工艺层没有的执行能力。

## 四、关于“使用氨基盐是不是氮同化”的稳妥口径

不能一概而论。

只有在以下条件满足时，才应写作氮同化或有机氮同化输入：
1. 氨基盐被细胞摄取；
2. 其氨基氮进入谷氨酸 / 谷氨酰胺等中心氮代谢节点；
3. 该氮最终进入产物、生物量或其他含氮代谢物。

若氨基盐只承担以下作用，则不能直接称为氮同化增强：
- 培养基补料
- pH 调节
- 缓冲盐
- 渗透保护或条件稳定剂

推荐表述：
“若该氨基盐作为可利用氮源被摄取并转入谷氨酸/谷氨酰胺节点，则构成有机氮同化输入；若仅用于培养条件调节，则不应等同于氮同化增强。”

## 五、在 proposal 中的最简压缩版

如果用户要求极简、只保留两问，可直接用：
1. de novo 元件能否做动态状态控制器？
2. de novo 元件能否做局部空间组织器？

再展开时，默认顺序是：
- 先用刘立明 / Lee 说明现有系统代谢工程已经解决了哪些层；
- 再指出蛋白级执行层仍是空位；
- 最后把 NarL / ppGpp / binder-linker / ClpX triage 放回这两个问题的执行框架内。

# Project Management Delivery Operations

Use this as the class-level project/delivery management skill.

## Core workflow
1. Define outcome, scope, stakeholders, constraints, and decision authority.
2. Break work into milestones, owners, dependencies, risks, and acceptance criteria.
3. Establish operating cadence: async status, risk review, decision log, escalation path.
4. Track delivery evidence: tickets, PRs, experiments, dashboards, artifacts.
5. Close the loop: launch checklist, retro, lessons, documentation updates.

## Subdomains
- **Project shepherd**: cross-functional coordination, stakeholder alignment, risk burn-down.
- **Senior PM task breakdown**: turn specs into small executable tasks with paths and acceptance criteria.
- **Jira workflow steward**: issue hygiene, branch/PR traceability, release linkage.
- **Experiment tracker**: hypothesis, variants, metrics, decision thresholds.
- **Studio operations**: resources, SOPs, tooling, vendor/process efficiency.
- **Studio producer**: portfolio-level coordination across creative/technical workstreams.

## Output standards
Prefer concise tables: owner, due date, dependency, status, risk, next action. Make unresolved decisions explicit.

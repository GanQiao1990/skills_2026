# 255字以内中文项目概述

这是从已吸收的 `project-summary-specialist` 中整理出的高频窄场景说明，保留为参考资料而不再单独作为技能存在。

## 适用场景
- 用户明确要求“项目概述 / 项目描述 / 项目说明”
- 明确要求中文
- 明确要求 255 字以内或相近的严格字数上限
- 常要求 markdown、单段输出或简洁标题

## 建议抽取字段
- 项目名称
- 项目时间
- 所属领域/指南
- 经费概算（若用户要求体现）
- 核心研究内容
- 创新点
- 预期成果

## 推荐逻辑框架
```text
背景意义 → 研究目标 → 研究内容 → 创新点 → 预期成果 → 项目意义
```

在 255 字以内时，可压缩为：
```text
背景/问题 → 目标 → 内容 → 创新/成果 → 意义
```

## 输出模板
```markdown
# 项目概述

[正文]

**字数：** X字（在要求范围内）
```

## 压缩原则
1. 保留事实信息，删除空泛修饰
2. 每句只承载一个主信息块
3. 首先压缩背景，其次压缩成果描述，最后才删创新点
4. 不凭空补充用户未提供的项目事实

## 典型用户要求
- “根据项目信息写一段 255 字以内的项目概述”
- “用 markdown 输出项目说明，一段话即可”
- “帮我把项目内容压成简洁的学术化简介”

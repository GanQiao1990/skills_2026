# NarL project academician briefing example

Use case:
- Source material: scientific thought / concept summary from a proposal-like document
- Audience: academician / senior scientific reviewer
- Deliverable: direct PPT deck, not a narrative memo

## Stable storyline extracted from session
1. Background: current de novo protein design has candidate-generation capability, but intracellular functional conversion and screening efficiency remain limiting
2. Research idea: establish a platform that connects design, candidate compression, cellular functional screening, and orthogonal validation
3. Completed foundation A: a six-stage de novo protein design and experimental-entry workflow
4. Completed foundation B: a ClpX-related de novo screening strategy closer to native intracellular functional triage
5. Validation chain: SPR/BLI + flow cytometry + confocal
6. Mechanistic bridge: NarL is the key node because it is a phosphorylation-dependent response regulator with system-level leverage
7. Preliminary evidence: oxygen-stress narl knockout causes lower OD, upgrading NarL from a theoretical node to an evidence-backed priority
8. Application 1: proximity engineering to enhance phosphorylation and improve stress resistance
9. Application 2: ppGpp sensor for stress-state monitoring
10. Application 3: dynamic NarQ-NarL coordination for growth-production balance
11. Innovation summary
12. Next-step outputs

## Durable lesson
For leadership-facing scientific briefings, this project class works best when the completed methodological platform is presented before the three application-layer hypotheses. NarL should remain the central mechanistic bridge rather than becoming one item in a broad list.

## Verification lesson
If thumbnail generation depends on PDF conversion and fails, verify the PPTX by direct package inspection:
- confirm file exists and size > 0
- inspect slide count
- extract slide titles/order from ppt/presentation.xml and ppt/slides/*.xml

This is a verification fallback pattern, not a claim that thumbnail tooling is generally unusable.
